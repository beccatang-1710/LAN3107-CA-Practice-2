## How to Use with Sora 2

For each clip:

1. **Upload reference image** — the same photo of the man and woman
2. **Set duration to 8 seconds**
3. **Copy the prompt** from the code block and paste into Sora's prompt field
4. **Generate** — Sora will produce a video with lip movements matching the exact words
5. **Download** as `clip_1.mp4`, `clip_2.mp4`, etc.

### Tips
- The dialogue in quotes tells Sora exactly what to lip-sync
- Upload the same reference photo every time for consistent faces
- The TTS pipeline will replace the audio later with the correct voice

### After All Clips Are Generated
1. Save all 18 clips into a folder
2. Create a `clip_mapping_p2.txt` file
3. Run the TTS pipeline (see `PIPELINE_GUIDE.md`)
